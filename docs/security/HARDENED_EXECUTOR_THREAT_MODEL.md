# Hardened executor threat model

Candidate code is untrusted. Threats include network/DNS/metadata access, host and credential reads, socket/mount/device escape, privilege escalation, process/memory/CPU/output/file exhaustion, hard-link inode bypass, forged worker framing, and unsafe diagnostics. Static validation remains mandatory. Docker isolation supplies an independent boundary; the runtime policy binds version, image/base digests, supervisor/child/build hashes, mounts, network, privileges, resources and environment.

Executor v2 exposes one writable private tmpfs at `/workspace`. Its inode ceiling is the declared concurrent-entry limit plus exactly one mount-root inode. Read-only input is separate; `/tmp`, HOME and host output are not alternate writable stores. Link, symlink, FIFO, device-node and Unix-socket APIs are statically forbidden. The image-owned supervisor independently counts all descendants, validates file types and sizes, and frames the only trusted stdout envelope after the candidate child exits. Candidate stdout and stderr are bounded untrusted logs.

Residual risks include Docker/runtime/kernel vulnerabilities, daemon privilege, architecture-specific images, macOS VM implementation details, and static-analysis limits. The local fixture runner has only post-run accounting and is not a kernel boundary. Real inode, mount, resource and isolation probes are mandatory for live eligibility; mocks or command inspection cannot approve an image.

The optional host workspace root is trusted runtime configuration, never candidate input. Missing components may be created privately, but the final component is checked without approving a followed final symlink and must remain a writable, searchable directory. Operations use unique children and delete only those children; the configured parent and unrelated siblings remain. The parent is not mounted writable into the container. Expected host-root failures are classified as `hardened_executor_workspace_root_unavailable` without exposing paths, OS errors, or tracebacks.

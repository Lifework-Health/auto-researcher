# Upstream feature boundary

Allowed: `Program` representation, bounded in-memory population bookkeeping and parent/ranking suggestions. Disabled: upstream evaluation, provider calls, API credentials, prompt persistence, embeddings, network, package installation, shell/subprocess execution, arbitrary files, persistence/resume, budgets/stopping, final selection and scientific judgement.

The adapter accepts one UTF-8 full-source replacement for the task-declared mutable file. Multi-file, path-bearing, dependency-requesting, provider-configuring, oversized or ambiguous envelopes fail with stable `upstream_*` codes. Upstream random IDs and timestamps are metadata only.

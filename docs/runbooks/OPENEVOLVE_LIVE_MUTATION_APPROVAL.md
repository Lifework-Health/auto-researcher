# Future live-mutation approval checklist

A live mutation remains prohibited until all are true: exact upstream adapter identity approved; exact executor image digest approved; real no-network/mount/environment gate passed; hardened runtime available; contract explicitly permits live model mutation; finite model/candidate/cost budgets; durable model-call reservation configured; explicit operator approval completed; and no scientific task is promoted without a separate scientific validation. Candidate-evaluation approval must include the seed baseline: one evolved candidate requires two evaluations, while the seed consumes no model call. A live approval must not be created when `openevolve_mutation_evaluation_budget_too_small` prevents the search from reaching mutation. PR 7 grants no live approval.
